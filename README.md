# KasaTakip – Küçük İşletme Gelir-Gider Takip Sistemi

## Projenin Amacı
Bu proje, küçük işletmelerin gelir ve giderlerini kolayca takip edebilmesi için hazırlanmıştır.

## Projenin Özellikleri
- Gelir kaydetme
- Gider kaydetme
- Toplam gelir hesaplama
- Toplam gider hesaplama
- Güncel kasa bakiyesini görüntüleme
- İşlem geçmişini listeleme
- Kasa raporunu TXT dosyasına kaydetme

## Kullanılan Teknolojiler
- Python

## Çalıştırma
Python yüklü bir bilgisayarda terminal üzerinden şu komut çalıştırılır:

python kasa_takip.py
